# NATS JetStream

## Introduction

Core NATS delivers messages only to subscribers connected at the moment of
publication. [NATS JetStream](https://docs.nats.io/concepts/jetstream) adds a
persistence layer on top, giving you at-least-once delivery.

## Setting up JetStream

First, connect to NATS server, for this example we'll use localhost connection:

```bash
nats context add localhost --description "Localhost"
```

Then, create a log stream for FlowG:

```bash
nats stream add FLOWG --subjects "flowg" --storage file --retention limits --defaults
```

## Testing

You can test the setup by sending a log to the pipeline using the `logger`
command:

```bash
logger -n localhost -P 5514 -t myapp1 'hello world'
```

You can then find your logs using `nats` CLI interface, with command:

```bash
nats stream get FLOWG 1
```
